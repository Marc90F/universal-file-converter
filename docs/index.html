Perché una semplice rinomina non funziona?

I formati di file contengono strutture binarie profondamente diverse. Cambiare il nome estensione produce solo file illeggibili o corrotti.

❌ Rinominare l'estensione (Finta conversione)

  • ⚠️ Header binario errato: Un MP4 rinominato in .mp3 contiene ancora gli Atom di sincronizzazione video, mandando in errore i lettori audio.
  • ⚠️ Crash di visualizzazione: Un file PNG a 32-bit trasparente rinominato in .jpg corrompe i visualizzatori perché JPEG non supporta il canale Alfa.
  • ⚠️ Excel illeggibile: Un file CSV è testo puro; rinominarlo in .xlsx non genera l'archivio compresso ZIP OpenXML richiesto da Microsoft Office.

✅ Universal File Converter (Vera ricodifica)

  • ✨ Demuxing & Decoding: Scompatta i flussi e decodifica i dati in matrici e campioni non compressi in RAM.
  • ✨ Compositing & Resampling: Applica filtri cromatici, campionamento PCM a virgola mobile, o ricostruzione XML tabelle.
  • ✨ Serializzazione conforme: Ricodifica da zero scrivendo l'header binario autentico e certificato dal consorzio del formato.

Avvio Rapido & Portabilità

Nessun installer invasivo. Basta clonare o scaricare la cartella e avviare il launcher nativo del tuo sistema operativo.

Avvio su Windows (10 / 11)

⬇ Scarica Pacchetto Completo (.ZIP)

Estrai lo ZIP e fai doppio clic su run.bat:

run.bat

Portabilità automatica: Se sul PC è presente solo Python di base, il programma avvia un bootstrapper con 1-click installer per le librerie e scarica automaticamente FFmpeg portable in locale.

Avvio su macOS (M1/M2/M3/M4 & Intel)

⬇ Scarica Pacchetto macOS (.ZIP)

Estrai lo ZIP, apri il Terminale nella cartella ed esegui:

chmod +x run.sh
./run.sh

Rilevamento Homebrew & Apple Silicon: Riconosce automaticamente /opt/homebrew/bin/ffmpeg su Mac Silicon e /usr/local/bin/ffmpeg su Mac Intel.

Avvio su Linux (Debian, Ubuntu, Fedora, Arch)

⬇ Scarica Pacchetto Linux (.ZIP)

Estrai lo ZIP ed esegui lo script shell nativo:

chmod +x run.sh
./run.sh

Supporto LibreOffice headless: Se presente sul sistema, converte automaticamente documenti DOCX in PDF con fedeltà tipografica nativa Linux.

Universal File Converter per Android (APK)

🤖 Scarica APK per Android

Pacchetto .APK per smartphone e tablet Android (tutte le architetture):

1. Scarica il file .apk sul tuo smartphone dalla sezione Releases.
2. Tocca il file scaricato per avviare l'installazione.
3. Se richiesto, consenti l'installazione da fonti sconosciute nelle impostazioni del dispositivo.

Architetture supportate: arm64-v8a (tutti gli smartphone moderni a 64-bit), armeabi-v7a (32-bit), x86_64 (emulatori Android e Chromebook). Compatibile con Android 7.0 (API 24) fino ad Android 14/15/16 (API 34).
